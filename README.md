Ctrl è un programma di censura del testo, creato per tenere dati sensibili anonimi.
nasce per far si che ogni professionista,azienda,utente non debba inviare dati personali suoi o di altri sul web e/o 
su agenti IA per avere una risposta, tutto ciò gira in locale nulla esce dal proprio pc.

[Cosa può censurare]
-Codice Fiscale,
-Partita IVA,
-Email,
-IBAN,
-Carta di Credito,
-Telefono,
-Indirizzo IP,
-Targa,
-Azienda,

COME UTILIZZARLO
1-installa il file bat
2-avvia il programma utilizzando = Python CTRL.py (nel terminale) o con doppio click sul file run.bat
3-utilizza le varie compinazioni di tasti

(ATTENZIONE, SE IL PROGRAMMA E AVVIATO CONTINUA A LAVORARE FINO A QUANDO NON VIENE CHIUSO)

COMBINAZIONE DI TASTI (eseguiti la prima volta censurano e incollano il file censurato se invece vengono utilizzati su un file censurato da programma fanno l'opposto ovvero traducono nuovamente il testo copiato nell'originale)

- Ctrl+C = copia con censura
- Ctrl+V = incolla con censura 
- esc = chiude il programma
